Open source · runs fully offline

Turn any document into a template, and prove it's exact.

Paste a config file, manifest, email or contract. templatize finds the values that should be parameters, writes a Jinja2 template, a .env and a render script, then checks that the template reproduces your original byte for byte.

How it works

  1. Paste

    Paste your document. Optionally add one to three other versions of it, such as staging and production, or two different customers' letters.

  2. Review

    Likely parameters are highlighted: IPs, hostnames, dates, emails, key/value pairs and repeated tokens. Anything that differs between your examples is suggested with high confidence. Accept, reject, rename, or select any text yourself.

  3. Verify

    The template is rendered with the extracted values and compared with your original, byte for byte, including whitespace, line endings and the trailing newline. A mismatch shows a red FAIL; it never slips through.

  4. Use

    Download template.j2, .env and render.py. Run uv run render.py to render it anywhere. Edit the values and preview the result live first.

Why not just ask an AI?

A chat model gives you a plausible template. templatize gives you one that's proven correct, privately and repeatably.

Exact, not approximate

Models are poor at copying long text verbatim. They quietly tidy whitespace, normalise line endings or "fix" typos. In a config or a contract one changed character is a bug. Here, every build is checked byte for byte.

The edge cases are handled

Text that already contains {{ }} or {% endraw %}, CRLF and mixed line endings, values containing quotes, # or $. Each has a deterministic rule, tested with thousands of random inputs.

AI assists, code decides

An optional local model can suggest names and spot missed values, but it never writes the template. Its output is schema-constrained, every quoted value is checked against your document, and anything invented is discarded.

Evidence, not guesses

Give it several versions of a document and it measures what varies, rather than guessing what might change between deployments.

Your data stays yours

Configs hold passwords; letters hold customer details. templatize runs entirely on your machine or server, offline, and never logs or stores what you paste.

Works with your AI, too

An MCP server lets Claude and other assistants use templatize as a tool. You get the AI's judgement with the tool's guarantees.

What's inside

  • Web UI: highlight, accept or reject, select any text, live preview, one-click zip
  • CLI: templatize suggest / templatize build
  • HTTP API and an MCP server (stdio and streamable HTTP)
  • Detectors: patterns, key/value, repetition, multi-example diff
  • Optional NER: names, organisations, addresses, money (GLiNER, CPU, no PyTorch)
  • Optional local LLM: better names and missed values (llama.cpp; CPU, NVIDIA or AMD via Vulkan)
  • Containers: non-root, read-only, and verified offline by an automated test
  • Pluggable engines: Jinja2 today; Helm, Liquid and others can be added

Get started

Docker / Podman

git clone https://github.com/welshstew/templatize
cd templatize
make up            # UI + API at http://127.0.0.1:8000
make up-ner        # …with the NER detector

Python (uv)

uv sync --all-extras
uv run templatize build nginx.conf --accept-all -o out/
cd out && uv run render.py > nginx.conf

Claude Code (MCP)

claude mcp add --transport http templatize \
  http://127.0.0.1:8000/mcp
